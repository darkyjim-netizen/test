#레포지터리 테스트옹
##테스트 내용

##해당 레포지토리에서 1회만 실시

아래와 같은 내용을 테스트 합니다.
 - 디렉터리 생성
 - 로컬 레포지터리 생성 : git init
 - 로컬 저장소에 목적지인 원격 저장소 지정 : git remote add origin
 "깃허브 레포지터리 주소"

 - 보안 정보(토큰) 등록 : url = "깃허브 토큰 레포지토리 주소"
 


----------------------------------------------------------------------

## 매 작업시 마다 push

아래 내용은 매 작업시 마다 진행

 - 코딩 및 작업
 - 작업 내용 등록 : git add
 - 작업 내용에 관한 메시지 등록 : git commit -m "메시지 내용"
 - 원격 저장소 (레포지토리)에 배포 : git push


------------------------------------------------------------------------

## 매 작업시 마다 pull

아래 작업을 ㅁㄴ저 선행되어 있어야 하며, 최초 1회만
 - 로컬 레포지터리 초기회 git init
 - 원격 저장소 지정 : git remote add origin 
 "레포지터리 주소"

 # 아래 내용은 매번 필요
 - git pull "래포지터리 주소" 브랜치명
